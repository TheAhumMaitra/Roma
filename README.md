# Roma

A Catholic Bible reader app. Available for Desktops, Laptops, etc! It uses `CPDV` Bible version!

# Installation
Easy to install for Linux, MacOS, Windows

### Note: Make sure you have all required system dependencies

## Clone this repo
```
git clone https://github.com/TheAhumMaitra/Roma.git
```

## Go to Directory and install it 
```
cd Roma && cargo install --path .
```
